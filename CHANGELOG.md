# Changelog

All notable changes to `laravel-nova-sso` will be documented in this file.

## [1.0.0] - 2024-01-20

### Added
- Initial release
- Support for Okta (SAML/OAuth2)
- Support for Microsoft Azure AD
- Manager pattern for handling multiple SSO drivers


## Unreleased

- Standardize Chinese-first and English README, installation, usage, contribution and licensing information.
